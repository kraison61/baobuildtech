# Master Content Inventory — เว็บใหม่ รับเหมาก่อสร้างครบวงจร

> ใช้ไฟล์นี้เป็นตัวตั้งในการหา keyword และผลิตเนื้อหา
> ทุกช่อง "Seed Keyword" คือ**คำตั้งต้นที่ต้องเอาไป validate** ยังไม่ใช่ Primary Keyword สุดท้าย
> จัดทำ: 26 ส.ค. 2569 · ใช้คู่กับ `แผนคอนเทนต์12เดือน-โครงสร้างเว็บ.md`

## 1. กติกา URL ที่ล็อกแล้ว

```
/services                                    Hub รวมบริการ
/services/{หมวด}                             หน้าหมวด (8 หมวด)
/services/{หมวด}/{ชิ้นงาน}                    หน้าบริการ = หน้าทำเงิน
/blog/{slug}                                 บทความ — แบนชั้นเดียวเสมอ
/portfolio/{slug}                            ผลงานรายชิ้น
/service-area/{province}                     หน้าพื้นที่
/projects/{ประเภทอาคาร}                       งานโครงการ B2B (แยกเพราะเป็น audience segment ไม่ใช่ประเภทงาน)
```

**กติกา slug**
- ตัวพิมพ์เล็ก คั่น `-` ไม่เกิน 5 คำ · ใช้อังกฤษเท่านั้น
- ห้ามใส่ปี · ห้ามใส่ชื่อจังหวัดในหน้าบริการ
- เลือก trailing slash แบบเดียวแล้วบังคับทั้งเว็บ ตั้ง 301 อีกแบบไปหาแบบที่เลือก

## 7. Worksheet สำหรับทำ Keyword Research

ทำทีละหมวด ไม่ต้องทำทั้ง 70 หน้าพร้อมกัน — เริ่มจากหมวดเรือธงเฟส 1

| หน้า/บทความ | Seed | Primary Keyword (ยืนยันแล้ว) | Volume | Secondary 3–5 คำ | Fan-out sub-queries 6–8 ข้อ | ประเภทหน้าที่ SERP ต้องการ | คู่แข่งหน้าแรก | ตัดสินใจ |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**ลำดับการกรอก (ห้ามข้าม)**

1. เอา Seed ไป **ค้น Google จริง** → ดูว่าหน้าแรกเป็นหน้าบริการหรือบทความ ถ้าไม่ตรงกับที่วางไว้ ให้เปลี่ยนประเภทหน้า ไม่ใช่ฝืนเขียน
2. เก็บ **People Also Ask** ทั้งกล่อง → กลายเป็น H2 และ FAQ
3. เก็บ **Google Autocomplete** (พิมพ์ seed แล้วดูคำต่อท้าย) → ได้ long-tail จริง
4. แตกเพิ่มด้วยสูตร `[ชิ้นงาน] × [modifier]` ในไฟล์ framework
5. เช็ค volume ใน Keyword Planner (location = ไทย, ภาษา = ไทย)
6. **เช็ค cannibalization** — ทับกับหน้าไหนในตารางข้อ 4-5 ไหม ถ้าทับ ให้รวมหน้าหรือแบ่ง intent แล้วลิงก์หากัน
